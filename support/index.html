Contact PartnR

Email partnrgolfsupport@gmail.com with the issue, iPhone model, iOS version and PartnR screen involved. Never send passwords or verification codes.

Email verification

Check Spam or Junk and search for Firebase or PartnR. Confirm the address is correct and wait before requesting another message to avoid delivery limits.

Sign-in problems

Use the same method used to create the account: email and password or Sign in with Apple. Include the exact error message when contacting Support.

Rounds and live scoring

Every app user should be signed in with an internet connection. Guests can be scored by the host but do not have cloud access without an account.

GPS and permissions

GPS distance is an estimate. Enable Location While Using the App and use it outdoors. Review photo, microphone, speech, calendar and notification permissions in iPhone Settings.

Safety and data requests

Use Report or Block from a golfer profile. For immediate danger, contact emergency services. For account correction, export or deletion, email from the address associated with the account.

Contact

Questions or requests: partnrgolfsupport@gmail.com.
